# TS Personal OS — PWA

Upload the contents of this folder to the root of your GitHub Pages repository.

Files:
- `index.html` — TS Personal OS v29.8
- `manifest.json` — installable PWA configuration
- `sw.js` — service worker for offline caching
- `icons/` — TS app icons, favicon, and Apple touch icon

After GitHub Pages deploys, open the Pages URL and install TS from the browser.
